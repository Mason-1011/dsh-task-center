# dsh-task-center-task-wake

**用途一句话**:任务接缝的时间面——宿主级定时器干两件事:到点起新会话干活(先探测路由可用性,额度没恢复就顺延;再在账本里消费掉这次到点,一次性规则清除、every 推进锚点;最后起一个全新代理会话,首条消息注入任务与上下文包),以及每日巡检(每天到设定时刻起一个会话,给所有未完结任务刷新现状)。

## Model Experience

**被拉起的会话是普通模型 actor**:首条用户消息(`[task-wake]` 前缀)携带目标、验收、状态与 contextPack 全文,指示其 `task_claim` → 完成 → `task_report(review)` 提交。该消息落在会话日志里(注入物可从日志重建)。会话创建时携带 cwd(任务没有自己的目录,锚定进程目录)——部署组装的 persona 段渲染 `{{cwd}}`,无 cwd 的机器会话首回合即组装失败(2026-08-18 部署验证发现的真 bug)。

**唤醒 actor 只做机械簿记**:wake-set(推进 every 锚点)/ wake-clear(消费一次性规则)在**起会话之前**提交——崩溃不会双重触发;claim / progress / submit 等工作动词一概不碰(权限矩阵:定时器列全空)。

**失败语义**:被拉起会话的 LLM 失败被包含并记日志;这一次到点已在账本中消费,不会重试(等到下个锚点)。持有人存活的到点任务同样只消费、不起会话。

## 唤醒前预检(preflight probe)

到点、任务无人持有时,**先探测后开火**:向被拉起会话的同一路由发一个 `maxTokens:1` 的极小请求(不带会话身份,不进会话日志,也不会触发 task-quota 的挂起——它只认带会话的失败)。

- 探测**阳性**(终死于 `QUOTA`):顺延——不消费这次到点、不起会话,规则保持到期,下轮再探;平台给了等待延时(`providerRetryAfterMs`)就按它退避,避免小轮询周期反复轰平台。额度一旦真正恢复(哪怕早于平台估计)立即开火。
- 其余一切(成功、鉴权/传输错误、探测自身异常)**照常开火**:探测坏了永远不挡活,真失败由被拉起会话自己暴露并被包含。
- 探测每轮 tick 至多一次(所有被拉起会话共用一条路由);退避是内存态,重启即失效,重启后立刻重探。

## 每日巡检(daily patrol)

配置了 `patrol.at` 后,同一个定时器每天在设定时刻(本地时间)起**一个**巡检会话:首条用户消息(`[task-wake] 每日巡检` 前缀)携带所有未完结任务的清单(精确 id、revision、状态、持有人、闲置天数、pack 最后一行),指示会话对每个任务调用一次 `task_patrol` 记录现状/下一步/卡点——**只观察**:不认领、不改状态、不刷新闲置时钟(搁置的任务巡检后依然显示搁置),他人持有的任务同样可巡检。

- **错过即跳过**:巡检没有持久化的"今天跑过了"标记,判定是进程内存态——本进程见过槽位**之前**的时刻、且此刻已过槽位、且今天没跑过,才开火。进程在槽位过后才启动,当天不补跑(重启也不会重复跑),等明天。
- **无预检探测**:巡检没有可消费的到点,不探测;会话失败被包含并记日志,当天不再重试。
- 巡检会话与被拉起的干活会话共用 `agent` 路由;额度墙的探测退避(`probeHoldUntil`)同样顺延巡检的首次开火。

## 配置(cordis.yml `config`,无硬编码可调项)

| 字段 | 含义 |
|---|---|
| `pollSeconds` | 轮询周期(秒),必须为正;挂载时跑一次立即检查;也是额度墙无延时的重探周期 |
| `agent.provider` / `agent.model` | 被拉起会话与巡检会话的模型路由,必填;预检探测同用此路由 |
| `patrol.at` | 每日巡检时刻,本地时间 `HH:MM`(24 小时制);缺省即关闭巡检;非法格式挂载即抛错 |

## 规则语义(与 dsh-schedule 记录形状一致)

- `after <秒>`:创建后 N 秒到点,一次性。
- `at <ISO>`:定点,一次性(接缝只校验可解析,是否过去由到点判断)。
- `every <秒>`:间隔下限 300 秒;锚点 `anchorAt` + 间隔即下次到点,每次触发把锚点推到**now 之后的第一个对齐点**(错过多次只按最新一次算,不补发)。

## Known Limitations and Deferred Work

- `done` 任务不触发唤醒(`wakeRules` 跳过):周期性例程需要"完成即重生"或模板机制(P2)。
- 死持有的释放由 task-reaper 负责(会话处置事件 + 挂载清扫),本包不管存活。
- 锚点推进失败(如 CAS 过期)只记日志跳过,不重试本周期。
- 探测退避只认平台延时;平台不给延时时按 `pollSeconds` 重探,无法主动滑到窗口结束点。
- 工具面暂不暴露 wake-set/wake-clear:模型走 `/task wake`/`/task nowake` 命令面;工具面补齐待 P1。
- 巡检的"今天跑过"判定是进程内存态(账本里没有它的持久化位置):同一天反复重启会在每个"见过槽位前时刻"的进程里各跑一次;槽位过后启动则当天跳过。
- 巡检对全部未完结任务只发一个会话、一轮清单:任务量大时清单消息随之变长,无分页。
